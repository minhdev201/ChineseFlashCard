🚀 CÀI ĐẶT (3 BƯỚC)
════════════════════════════════════════════════════════════════════════

BƯỚC 1: Cài dependencies
  $ npm install
  
  Nếu lỗi: npm install express @types/express @types/node

BƯỚC 2: Chạy server
  $ npm run dev:api
  
  Output: 🚀 Server running at http://localhost:5173
          📚 API endpoint: http://localhost:5173/api/random-vocab
  
  Test: Mở http://localhost:5173/api/random-vocab trong browser

BƯỚC 3: Load extension vào Chrome
  1. Mở: chrome://extensions/
  2. Bật "Developer mode" (toggle góc trên phải)
  3. Click "Load unpacked"
  4. Chọn thư mục: ExtensionVocab
  5. Mở tab mới → Thấy từ vựng tiếng Trung! 🎉

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════

❌ "Cannot find module 'express'"
   → npm install express @types/express @types/node

❌ Extension không load
   → Check Developer mode, đúng thư mục, reload extension

❌ Không thấy từ vựng
   → F12 Console, server chạy chưa, test API

❌ CORS Error
   → Dùng npm run dev:api (có CORS config)
